# 鲸选暗线 · 通关说明

一个伪装成 Windows 桌面的单人解密游戏。玩家扮演代号「夜莺」的间谍，盯着一份鲸选商城的离线镜像：前台只卖日用品，旧货架早被下架归档。线索散在店铺公告、买家评价和客服自动回复里；按评价里写的先后凑齐四件日用品提交自提单，浏览器才会跳进「S07 归档区」——和商城同一套布局，但底色、字色全换成了暗色，架子上摆着旧物、遮蔽过的未登记件和没编进目录的条目。核对盘点口令调出交接单，最后用聊天软件向上线「老鸦」上报情报。

- **成品**：`index.html`（单文件，约 0.5 MB，断网也能通关；日用品产品图联网时显示）
- **仓库**：https://github.com/DZF2112009/jingxuan-dark-line （克隆下来双击 `index.html` 即可）
- **时长**：首次通关 20–40 分钟
- **平台**：桌面 Chrome / Edge（双击打开即可）；窄屏有基础适配，没有为触屏做专门优化

## 运行

直接双击 `index.html`。样式、脚本、旧物图都内嵌在这一个文件里；8 件日用品的产品图走网络，断网时卡片会自动换成米色底 + 商品名的占位块，不影响解谜。

> 首次打开有一小段启动动画，随后弹出任务简报。点「开始」进入桌面。

## 先看看后面几页（调试跳转）

不想从头解也能翻到后面几页：

跳转只改内存状态，不写文件；`__AX.jump('reset')` 回到开局。

## 手机上能玩吗

能，但它是「桌面窗口」的隐喻，手机上会退化成单窗口：窗口自动铺满屏（`.win` 在 620px 以下强制 `100vw - 8px` 宽、`100dvh - 60px` 高），聊天和商城各占一整屏，靠任务栏图标来回切（点当前窗口图标会最小化，点另一个就切过去）。已实跑验证：390 × 844 触屏环境下从开局 → 加购四件 → 自提单 → 归档区 → `K7` → 上报 → 结局〈自己人〉全通，控制台零报错，`body.scrollWidth = 390` 无横向溢出。

配套的几处手机专修：

- 所有可输入内容（聊天框、盘点口令）字号提到 16px，iOS 聚焦时不会再整页放大。
- 按钮加高（加购按钮、口令按钮），点得准。
- 提示条（toast）自 v2.5 起停用，手机上也不会再有浮窗压住输入区。
- 商品与归档件两列排布（620px 以下），卡片是「图 + 文」。

局限：屏幕小，一次只看得到四五张卡；拖窗、缩窗这些桌面乐趣基本没有；触屏没有悬停效果。想要完整体验还是建议桌面浏览器，手机当作「躺床上推进剧情」的备选。

## 一句话流程（剧透）

> 店铺公告（旧货架归档 + 那串字母）→ Base64 解出 `SHIPPING` → 商城「源码」里那段拆掉的旧客服脚本给出摩斯 `K7` 与门规 → 按评语次序把纸巾 / 洗洁精 / 白毛巾 / 电池装进车、直接结算 → 跳进 S07 归档区 → 样品第 7 张照片（底板刻字）→ 口令 K7 调出交接单 → 上报 K-07。

## 设计意图与可证伪假设

- **假设 1**：一家「只剩日用品」的店，反而让玩家更想找不卖的东西。观察信号：进店后第一分钟是否点开「店铺公告」。
- **假设 2**：把暗语串（Base64）放在公告里、把 1947 顺带写成注脚，玩家会先读公告再乱点。观察信号：公告页停留时长、解码器 Base64 使用率。
- **假设 3**：「次序写在买家评价里」比把顺序直接给出更有调查感。观察信号：四件是否按 d1→d2→d5→d8 加购；错误次序是否集中在「先拿最贵的」。
- **假设 4**：暗网与商城同一套布局、只换配色，比另做一个怪站点更可信。观察信号：第一次进入时是否意识到「还是这家店」，是否回商城核对价格。
- **假设 5**：遮蔽件（斜纹打码块）承担「这页不该被看见」的情绪。观察信号：进归档区后是否先停在未登记件那一段，是否点样品卡。
- **假设 6**：结局三选一能让玩家在「任务成功」之外做一次道德选择。观察信号：三个结局的选择分布。

## 默认参数

- 评 S：15 分钟内通关；A：25 分钟内；其余 B。不设提示，卡住只能自己回页面里找。
- 上报校验为容错匹配：货号（K-07/K7）、城市（布宜诺斯艾利斯/布宜）、时间（07:40/7:40/0740/7点40）三项齐全才算过。
- 自提单：按 `d1 → d2 → d5 → d8` 加购（纸巾 / 洗洁精 / 白毛巾 / 电池），次序对了直接点结算；批次由系统填 `1947`，玩家不需要输入。车内多买的日用品不占四件名额，只在车尾提示。
- 商城地址栏为只读；归档区只能由自提单跳转进入，搜索也搜不到它。盘点口令可输入 `K7` 或摩斯原文，页内自行解码。

## 范围说明

- 单关卡、三结局分支，不含存档；刷新页面即重开。
- 商城为离线只读镜像，唯一的例外是「自提单」；购买 / 支付 / 物流均为叙事道具，不接任何真实交易。
- 「暗网」「暗门」都是游戏内的虚构页面，没有真实地址，也不会打开任何外部网络。
- 购物车不做持久化，刷新或重开即清空。
- 音效为 WebAudio 合成的轻提示音，可在任务栏右下角静音。
- 移动端仅保证不裁切、可拖动与可滚动，未针对触屏手势做专项优化。
- 全部品牌、人物、地址、货号均为虚构。
